# Reporting a security issue

Please do not open a public issue for a vulnerability.

Email **security@dbmn.io** with what you found, how to reproduce it, and the version
(`Hub → Account` shows it). You will hear back within three working days, and we will tell you
when a fix is released and credit you if you wish.

What is in scope: this repository (the VS Code extension, the web app, the desktop app) and the
public backend schema and functions it ships. The hosted service at dbmn.io is run by Flexion
Tech Pty Ltd; report issues with it the same way.
